About QuickNotes

QuickNotes is a simple app for writing down ideas, reminders and to-dos the moment they come to mind. It keeps everything in one place so nothing gets forgotten.

How to use QuickNotes

  1. Open the QuickNotes home page.
  2. Type your note into the text box.
  3. Click "Add Note" or press Enter.
  4. Find your note in the "Your notes" list.

Features

  • Add notes quickly
  • See all your notes in one list
  • Works on phones and computers

Keyboard shortcuts

Shortcut Action
Enter Add the note
Ctrl + S Save the file in VS Code
